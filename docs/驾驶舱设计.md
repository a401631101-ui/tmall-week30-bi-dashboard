## 4. 数据标准化规则

### 4.1 完整度模型（`index.json`，非「完整/不完整」二值）

```ts
interface WeekIndex {
  week: number;                  // 1..32
  period: string;                // "2026-08-03 ~ 2026-08-09"
  monday: string;                // ISO 周一日期，week_monday 归组后的锚点
  totalRows: number;             // 该周实际行数（去重后）
  categoryCount: number;         // 入榜类目数
  categoryTotal: number;         // 15
  categoryCoverage: number;      // categoryCount/15，0..1
  presentCategories: string[];   // 入榜类目 key
  missingCategories: string[];   // 缺失类目 key
  quality: "complete" | "sparse" | "partial";
  rowAnomalies: {
    duplicateProductIds: number; // 同周同类目重复商品ID2 数
    nullId: number;              // 商品ID2 空值数
    nullRank: number;            // 行业排名空值数
    nullVisitors: number;        // 访客数空值数（源数据已知 15 行空）
  };
  riskNotes: string[];           // 风险提示文案
}
```

- `complete` = 15 类目齐全且无异常；`sparse` = 类目 < 15（如第 5–14 周）；`partial` = 有拆分日期/重叠周期需合并（第 1、8 周）。
- **已知稀疏周基线**：第 5 周 14 类目；第 6–8、10–14 周 8 类目；第 9 周 1 类目；第 1、8 周为拆分日期周（`week_monday` 归组去重）。

### 4.2 品牌标准化 + 雨虹品牌群别名表（v1.1 已确认）

源数据无品牌列，品牌由 `商品名称` 提取。雨虹系三档默认映射：

| 档位 | 匹配规则（已确认） | 说明 |
|---|---|---|
| `东方雨虹` | 商品名称含「东方雨虹」 | 雨虹子品牌①（重点观测） |
| `雨虹飞鱼` | 商品名称含「飞鱼」 | 雨虹子品牌②（重点观测，地漏等五金线） |
| `雨虹（裸）` | 含「雨虹」且不含「东方/飞鱼」 | 雨虹子品牌③（重点观测，如「雨虹美缝剂」） |
| `雨虹品牌群` | ①+②+③ 并集 | 群组（我方品牌，重点观测） |

```ts
interface BrandDim {
  canonical: string;             // 标准名，如 "东方雨虹"
  aliases: string[];             // 别名/变体
  tier: "东方雨虹" | "雨虹飞鱼" | "雨虹（裸）" | "雨虹品牌群" | "其他";
  isMine: boolean;               // tier 属于我方（三档任一为 true）
}
```

- 「我方品牌」筛选器档位：`东方雨虹` / `雨虹飞鱼` / `雨虹（裸）` / `雨虹品牌群`（= 三子品牌并集）。
- 非雨虹系品牌需另建别名表（如「三棵树」「德高」「立邦」「潜水艇」等，供竞品对比与标准名归一）。

### 4.3 类目标准化（`dimensions/categories.json`）

15 类目、4 分组、源全路径 → 短名映射（已从 `analytics.json.categoryLatest` 取证）：

```ts
interface CategoryDim {
  key: string;          // UI 名，如 "美缝/勾缝剂"
  sheetName: string;    // Excel sheet 名，如 "美缝_勾缝剂"
  group: "涂料与防水" | "胶粘与辅材" | "卫浴五金" | "厨卫水件";
  fullPaths: string[];  // 源「类目名称」全路径
}
```

4 组：涂料与防水(防水涂料/地坪漆/水性木器漆/艺术漆/乳胶漆)、胶粘与辅材(美缝·勾缝剂/玻璃胶/瓷砖胶)、卫浴五金(地漏/毛巾架/角阀)、厨卫水件(面盆龙头/恒温花洒套装/厨房龙头/水槽套餐)。

### 4.4 缺失值语义（关键）

严格区分三种状态，禁止混同：

- **缺失（未入榜）**：该周该商品/品牌不在 Top100 → 排名无值，不等于 0。
- **数值 0**：`支付买家数/访客数` 真实为 0（极少）。
- **空值/异常**：`商品ID2` 空、`访客数` 空（15 行）→ 标记为 `nullId/nullVisitors`，不参与聚合。

## 5. 数据模型 — JSON Schema（TypeScript 风格）

### 5.1 `reports/week-{NN}.json`

```ts
interface WeekReport {
  week: number;
  period: string;
  summary: ExecutiveSummary;
  kpis: Kpi[];
  brandBoard: BrandTrend[];
  top10: ProductTrend[];
  anomalies: Anomaly[];
  categories: CategoryReport[];

interface ExecutiveSummary {
  generalJudgment: string;
  strongBrands: string;         // 叙事 + 结构化 evidence（见下）
  weakBrands: string;
  strongProducts: string;
  riskProducts: string;
  segmentOpportunities: string;
  nextWeekWatch: string;
  conclusions: Conclusion[];    // 可解释结论（§11）
}

interface Conclusion {
  text: string;                 // 叙事文案
  current: number;              // 当前值
  previous: number;             // 上周值
  delta: number;                // 变化量
  affected: string[];           // 影响品类/商品ID
  ruleVersion: string;          // 结论规则版本，如 "yuhong-shrink-v1"

}

interface Kpi { label: string; value: string | number; delta?: number; }

interface BrandTrend {
  brand: string;
  categories: number;
  top10: number[];  top30: number[];  top100: number[];   // 长度 3（T-2→T-1→T）
  tag: string; judgment: string;
  isMine: boolean;
}

interface ProductTrend {
  rank: number; category: string; brand: string; id: string; name: string;
  track: number[];              // 三周排名轨迹 [n,n,n]
  status: string; judgment: string; direction: string;
  popularity: string;           // 访客量级分桶（原「搜索人气」）
  conversion: string;           // 转化率分桶
  isMine: boolean;
}

interface Anomaly {
  type: "连续两周上升" | "连续两周下降" | "单周上升超过20名" | "单周下降超过20名" | "新进前100" | "跌出前100";
  category: string; brand: string; id: string; name: string;
  rank: number; prevRank: number; delta: number;
  direction: string; action: string; judgment: string;
  priority: "S" | "A" | "B" | "C";    // §6.5 优先级规则
  isMine: boolean;
}

interface CategoryReport {
  category: string;
  present: boolean;             // 稀疏周标记
  judgment: CategoryJudgment;
  brands: CategoryBrandTrend[];
  top10: ProductTrend[];
  anomalyZone: { upTwoWeeks: Anomaly[]; downTwoWeeks: Anomaly[]; upBigJump: Anomaly[]; downBigDrop: Anomaly[]; newEntry: Anomaly[]; exitTop100: Anomaly[]; };
  segments: SegmentTrend[];
}
```

## 6. 全局筛选状态（L3）

```ts
interface GlobalFilter {
  week: number;                       // 1..32，默认最新（32）
  window: "单周" | "最近4周" | "最近8周" | "全部周期";
  category: string | "全部";          // 类目
  brand: string | "全部";             // 品牌
  mine: "东方雨虹" | "雨虹飞鱼" | "雨虹（裸）" | "雨虹品牌群";   // 我方品牌档位
  rivals: string[];                   // 对比品牌 1..5
}
```

规则：

- 选类目后：品牌列表只显示该类目**实际入榜品牌**，按本周 Top100 强度降序。
- 当前品牌不属新类目时，自动回落「全部品牌」。
- 顶部常驻口径条：`第32周｜防水涂料｜东方雨虹 vs 三棵树｜最近8周`。

### 6.1 异动优先级 + 默认排序（§07 专项 / 06 异动页）

- **S 级**：雨虹核心产品 或 进入 Top10。
- **A 级**：单周变化 > 20 名。
- **B 级**：连续两周变化。
- **C 级**：普通新进 / 跌出。

默认排序：① 东方雨虹/雨虹飞鱼 → ② 类目头部品牌 → ③ 排名变化最大 → ④ 高人气高转化。

### 02 市场与品类

四象限：高规模高增长=重点投入 · 高规模低增长=效率竞争 · 低规模高增长=机会试验 · 低规模低增长=谨慎投入。

① 品牌强度榜（Top10/30/100 席位、覆盖品类、环比、连续增长周数）② 品牌 32 周趋势（4/8/全周期，东方雨虹固定高亮，多竞品对比）③ 品牌×品类热力矩阵（色=Top100 席位；红=增长、绿=下降、灰=持平）。

### 04 产品竞争
各类目 Top10 / 雨虹产品矩阵 / 上升最快 / 下降最快 / 六类异动。

### 05 细分机会
词云升级为「细分方向机会榜」：Top100 规模 / 近 4 周增长 / Top10 集中度 / 主要品牌 / 新进产品数 / 访客量级 / 转化表现 / 雨虹覆盖 / 推荐行动。
机会评分 = `规模增长 + 新品进入速度 + 搜索热度 + 转化表现 − 品牌集中度 − 雨虹当前覆盖`。重点词（彩砂/防霉/结构胶/抽拉/纳米）按机会等级定字号/颜色/权重。

### 06 异动预警

### 07 雨虹专项

## 8. 已确认口径（v1.1 决策记录）

1. **品类规模** = `访客数`（流量规模；GMV 不可用）。
2. **「搜索人气」** 统一改名 **「访客量级」**（= 访客数分桶）。
3. **雨虹品牌群**：`东方雨虹 / 雨虹（裸）/ 雨虹飞鱼` 均为雨虹系子品牌，全部作为重点观测；`雨虹品牌群` = 三子品牌并集（§4.2）。
4. **时间窗口语义**：「较上周增减」= 单周环比；「最近 4/8 周」= **滚动均值**（非累加）。

| 品类规模 | 品类入榜商品流量规模 | `sum(访客数)` | 分周、分平台可选 |
| 品类增长率 | 周环比 | `(本周−上周)/上周` | 稀疏周以相邻有数据周为基；4/8 周窗口用滚动均值 |

| 连续增长周数 | Top100 席位连续环比>0 | 时序滑窗 | |
| 转化率 | 买家/访客 | `支付买家数/访客数`，分桶区间 | 源数据 15 行访客为空 |
| 访客量级（原「搜索人气」） | 访客数分桶 | `访客数` 分桶 `1万~2.5万` 等 | 已改名 |

## 10. 统一视觉逻辑

- 红=增长/上升/机会 · 绿=下降/收缩 · 橙=风险/观察 · 蓝=市场及中性 · 紫=细分方向 · 灰=持平/无变化。
- 东方雨虹/雨虹飞鱼：浅红背景 + 红色边框。
- 避免全页大面积红色，仅突出真正重要信息。

## 11. 可解释结论规则
